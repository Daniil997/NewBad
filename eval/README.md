# Оценка качества

Демо-прогон измеряется без ключа и без видеокарты. Функции лежат в `eval/metrics.py`, проверки — в `tests/e2e/`.

- Покрытие ссылками: доля фактов и позиций банка, у которых ссылка есть в источниках карточки.
- Доля подтверждённых утверждений: факт найден в тексте новости, цитата банка — на странице документа, вывод модели ссылается на источник или признак профиля. Число в выводе должно быть в этом источнике.
- Лента: precision@3 и nDCG@5 по `personalization_cases.yaml`. Новость без оценки считается нулём. Одинаковые id не повторяются. Более старая новость того же типа с штрафом за дубль стоит ниже свежей. Дата разметки — поле `today` в этом файле.
- Банк: доля документов каталога с прочитанным `pages.json` и доля страниц, которые попали в индекс. Страница с ошибкой или слишком коротким текстом в индекс не входит и видна в отчёте.
- Запрос: задержка и токены карточки. Стоимость — токены на `rub_per_1k_tokens` из `config/llm.yaml`. Пока тарифа нет, ставка 0, и mock-запрос стоит 0.

Сравнение моделей на 30–50 парах остаётся отдельным прогоном: для него нужен явный live-вызов, этот набор его не делает.
