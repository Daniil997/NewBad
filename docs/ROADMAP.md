# План работ

Подробный порядок разработки: `Doc/Поэтапный план разработки.md` рядом с репозиторием. Здесь тот же маршрут чек-листом. Этап закрываем целиком, затем берём следующий.

Стек зафиксирован: Python 3.11, FastAPI, Pydantic, DuckDB, SQLite, pytest; интерфейс — TypeScript, React, Vite. Нейросеть подключаем на этапе 6. До него работает режим `mock`.
