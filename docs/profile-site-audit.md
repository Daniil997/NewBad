# Проверка «Сайт и источники» — 26 октября 2026

Практическая оценка по проверенным сценариям: около **5/10 до изменений и 8/10 после**.
Это инженерная оценка небольшой выборки, а не статистическая оценка всех сайтов.

## Методика и результаты

Проверены реальные публичные сайты МТС, «Лаборатории Касперского» и «Магнита».
Использован настроенный маршрут `real.profile_site`, облачная Gemma, без подмены ответов модели.
Каждый прогон создавал новые аккаунты в отдельной SQLite. Рабочие профили и настройки не менялись.
Для каждого аккаунта проверены регистрация, сохранение сайта, анализ, отсутствие самовольного
заполнения, явное принятие предложений, повторное чтение профиля и сохранённых источников.

МТС и Kaspersky приведены по общему повторному прогону, «Магнит» — по финальному прогону
после исправления кавычек в цитате. Количество предложений может меняться между ответами модели.
Рост количества сам по себе не означает рост точности: каждое принимаемое предложение проходит
проверку наличия цитаты и соответствия значения источнику.

В браузере дополнительно пройден сценарий МТС: регистрация, «Сохранить и изучить сайт»,
проверка регионального перенаправления, принятие четырёх предложений, перезагрузка,
повторный вход в профиль и раскрытие четырёх источников с цитатами.

## Найденные проблемы и исправления

- Обходчик терял полезные ссылки за повторяющимся меню. Ссылки теперь учитываются без дублей,
  очередь отдаёт приоритет страницам о компании даже после обнаружения на следующем уровне.
- «Магнит» не отдаёт обычный текст тела страницы без JavaScript, но публикует описание в HTML.
  Теперь читаются `description` и `og:description`; скрипты и скрытые шаблоны не исполняются.
- Заголовок страницы не принимался как доказательство названия бренда. Теперь модель может
  цитировать опубликованный заголовок, сохраняя привязку к той же странице.
- Разные тире и кавычки приводили к потере правильных предложений. Сопоставление допускает
  эти различия, а в источнике сохраняется дословный фрагмент оригинала.
- Одиночный отраслевой тег строкой терялся из-за формы ответа модели. Он приводится к массиву
  и проходит прежние проверки словаря и подтверждающей цитаты. Уточнена схема в запросе модели.
- Слишком свободный пересказ проходил по совпадению половины ключевых слов. Проверка ужесточена;
  модель получает указание предлагать короткие фрагменты исходного текста. География офисов
  без свидетельств о рынках или поставках больше не принимается как география сбыта.
- Скрытые элементы и самозакрывающиеся теги могли портить извлечение. Добавлен учёт вложенности,
  `hidden`, `aria-hidden`, `display:none` и пустых HTML-тегов.
- При ошибке первого публичного IP-адреса остальные не проверялись. Теперь есть ограниченная
  попытка соединения с другими предварительно проверенными адресами в общем лимите времени.
- После смены сайта оставались предложения прежней компании. Они удаляются при сохранении;
  результат незавершённого анализа старого сайта не сохраняется и не возвращается для принятия.
- Принятые или отклонённые ранее значения нельзя было снова предложить после очистки поля.
  Новый явный анализ теперь может обновить такое предложение.
- Одновременные подтверждения могли потерять изменения другого запроса. Изменение профиля
  и подтверждение защищены транзакциями SQLite с блокировкой записи до чтения.
- Ошибка настройки модели заставляла ждать пять минут. Сбой до чтения страниц теперь допускает
  повтор после исправления настройки; блокировка одновременных анализов и лимит обычных запусков сохранены.
- Отсутствие доступных страниц выглядело как успешный анализ без новых сведений. Интерфейс
  различает эти результаты, показывает перенаправление, ограничения JavaScript и частичное чтение.

## Практические ограничения

Система читает статический публичный HTML и его метаданные. Она не исполняет JavaScript,
поэтому полнота динамических сайтов остаётся ограниченной. «Магнит» теперь даёт базовый профиль,
но его полноценные страницы и меню требуют другого способа публикации или безопасного рендеринга.

При проверках внешний сервис модели временами отвечал ошибками соединения и протокола.
Успешные итоговые прогоны не гарантируют постоянную доступность провайдера. Получение цитаты
также не заменяет смысловую проверку владельцем: региональная страница МТС не доказывает
местоположение головного офиса, а рекламная формулировка остаётся утверждением самого сайта.

## Воспроизведение

Из каталога `NewBad`, при установленных dev-зависимостях и настроенной модели:

```powershell
.\.venv\Scripts\python.exe scripts/audit_profile_sites.py --output .qa/sites-check.json
```

Это отдельная живая проверка с реальными сетевыми вызовами и расходом настроенной модели.
JSON, тестовые базы и снимок интерфейса сохраняются в исключённой из Git папке `.qa/`.
Скрипт принимает `--sites` для выбора других публичных сайтов. Отчёт содержит предложения,
ответы модели, принятые поля и число сохранённых источников; пароли и токены не выводятся.
