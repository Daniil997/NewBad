# Сторонние компоненты

Заполняется по мере подключения. Перед сдачей проверить каждую строку.

## Модели (приложение 3 кейса)

| Модель | Как используется | Лицензия и условия |
|---|---|---|
| Gemma 4 26B A4B | light-уровень, локально или через API | уточнить |
| Qwen3.6 35B A3B | heavy-уровень | уточнить |
| GLM-5.3-Flash, DeepSeek-V4.1-Flash, Kimi-K2.6 | только через API кейса, если используются | уточнить |

## Программные компоненты

| Компонент | Версия | Лицензия |
|---|---|---|
| FastAPI, Uvicorn, Pydantic, httpx, PyYAML | см. requirements.txt | проверить |
| llama.cpp, Ollama | см. docker-compose.yml | проверить |

## Данные

- Обезличенные данные клиентов и платежей из кейса.
- Аналитические материалы Центра макроэкономических исследований Альфа-Банка (приложение 2 кейса).
- Внешние новости: источник, дата, условия использования для каждой записи в `data/news`.

## Смоделированные интеграции

- Макет главного экрана интернет-банка Альфа-Бизнес.
