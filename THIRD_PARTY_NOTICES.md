# Сторонние компоненты

Проверено 22 октября 2026 по метаданным установленных пакетов, `package.json` интерфейса и карточкам моделей, которые реально названы в `config/llm.yaml`. Веса моделей, PDF банка и CSV выгрузки в репозиторий не входят.

## Модели

Рабочие режимы называют две модели. Остальные id из инструкции кейса записаны в белый список и текущими режимами не вызываются. Веса в Git не кладутся, приложение их не скачивает: `models/README.md` и `scripts/llama-server.ps1` только указывают официальный файл, который пользователь кладёт сам.

| Модель | Где названа | Лицензия | Как соблюдаем |
|---|---|---|---|
| Gemma 4 26B A4B, `google/gemma-4-26b-a4b-it` | `local_only`, `local_dual`, `hybrid`; локальное имя `gemma-4-26b-a4b` | Apache 2.0. Карточка `google/gemma-4-26B-A4B`, ссылка на лицензию Gemma 4 | Веса не распространяем. Локальный файл — официальный GGUF или уже установленная Ollama-модель |
| Qwen3.6 35B A3B, `qwen/qwen3.6-35b-a3b` | тяжёлый уровень `local_dual`, `hybrid`, `cloud_only` | Apache 2.0. Файл LICENSE репозитория `Qwen/Qwen3.6-35B-A3B` | Веса не распространяем. В демо режим `mock`, запрос к модели не уходит |
| `z-ai/glm-5.3-flash`, `deepseek/deepseek-v4.1-flash`, `moonshotai/kimi-k2.6`, `qwen/qwen3-vl-30b-a3b-instruct` | только белый список `models.api` | Весов в проекте нет, режимы эти id не выбирают | Отдельный вызов не описан в инструкции запуска. Qwen3-VL в сценарии новостей не используется |

Прежние Gemma Terms of Use относятся к более ранним поколениям. У Gemma 4 в карточке модели указан Apache 2.0.

## OCR и локальный сервер модели

В репозиторий эти программы не входят. Их ставит тот, кто запускает импорт PDF или локальную модель.

| Компонент | Лицензия | Как вызывается |
|---|---|---|
| Tesseract OCR | Apache 2.0 | `PATH` или `C:\Program Files\Tesseract-OCR\tesseract.exe`. Нужен для сканов в `python scripts/prepare.py bank` |
| `rus.traineddata` | Apache 2.0, официальный набор tessdata | файл лежит в `data/tessdata/` и в Git не входит |
| llama.cpp, программа `llama-server` | MIT | пользовательская сборка с CUDA. `scripts/llama-server.ps1` её не скачивает |
| Ollama | MIT | необязательный локальный адрес `http://127.0.0.1:11434/v1`, если веса Gemma уже стоят там |

Демо-режим `mock` эти программы не запускает.

## Данные и ограничения

| Источник | Что хранит проект | Ограничение, которому следует инструкция |
|---|---|---|
| Выгрузка кейса, три CSV | Файлы остаются в `../DATA/company_profile`. В Git их нет | `data/README.md` запрещает коммит CSV. Идентификаторы обезличены. Журнал приложения не пишет значения профиля |
| PDF аналитики Альфа-Банка, приложение 2 | Файлы остаются в `../DATA/bank_analytics`. Распознанный текст — в `data/bank/extracted/` и в Git не входит | Материал банка запрещает копирование без письменного разрешения. Инструкция не публикует PDF и не изменяет исходный файл. В Git лежит паспорт `data/bank/key_rate.json`: его текст помечен как демонстрационный конспект, не оригинальный отчёт |
| Банк России, лента `https://www.cbr.ru/rss/RssPress` | Единственный настроенный живой источник новостей | Импорт сохраняет заголовок, дату, адрес и выдержку не длиннее 600 символов. Полный релиз не копируется. Каталог `data/news/imported/` в Git не входит |
| Демо-новости в `data/news/*.json` | Короткие тексты прототипа и ссылки на публичные страницы Банка России, Росстата, Минфина, EIA и LBMA | Это не копии статей этих сайтов. В карточке остаётся адрес страницы |
| Макет «Альфа-Бизнес» | Экран прототипа в `ui/` | Это макет сценария, не интернет-банк Альфа-Банка и не его товарный знак в качестве своего продукта |

Инструкции запуска в `README.md`, `data/README.md` и `models/README.md` этому соответствуют: закрытые CSV, PDF, распознанные страницы, импорт RSS, журнал и веса в репозиторий не предлагается добавлять. Демо собирается из файлов, которые уже лежат в Git, без ключа и без скачивания моделей.
