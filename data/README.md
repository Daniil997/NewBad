# Данные

- `raw/` — исходные CSV и PDF кейса. В git не попадают (см. `.gitignore`).
- Выгрузка кейса лежит рядом с репозиторием: `Doc/Данные данные` (`df_Uid_data_hack.csv`, платежи и связи физлиц, девять PDF аналитики банка). При запуске приложения она подхватывается сама. В интерфейсе для показа три компании из этой выгрузки: `U_23929`, `U_12470`, `U_416505`. Полный список на 85 тысяч компаний в переключатель не выводится. Тесты читают `demo/`.
- `demo/` — синтетические демо-клиенты, попадают в репозиторий и используются тестами.
- `news/` — корпус новостей: JSON с источником, датой, URL, выдержкой и извлечёнными фактами.
- `bank/` — паспорта материалов банка: тезисы, допустимые цитаты с номером страницы, чанки.
- `cache/` — кэш ответов LLM и готовых карточек (в git не попадает, кроме `replay`-набора, который добавим отдельно).
