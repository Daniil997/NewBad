# Данные

- Исходные данные кейса находятся рядом с репозиторием и не попадают в Git: `../DATA/company_profile/` содержит три клиентских CSV, `../DATA/bank_analytics/` — PDF аналитики банка. Приложение обнаруживает эти папки автоматически при локальном запуске; Docker Compose монтирует их read-only и задаёт `CASE_DATA_DIR` и `BANK_PDF_DIR`. Старые расположения (`../DATA/` для CSV и `../Doc/Данные данные/` для PDF) остаются резервными.
- В интерфейсе для показа три компании из `config/case_clients.yaml`. Показатели профиля туда не записываются, они читаются из CSV. Полный список на 85 тысяч компаний в переключатель не выводится. Тесты читают `demo/`.
- `demo/` — синтетические демо-клиенты, попадают в репозиторий и используются тестами.
- `news/` — корпус новостей: JSON с источником, датой, URL, выдержкой и извлечёнными фактами.
- `bank/` — паспорта материалов банка: тезисы, допустимые цитаты с номером страницы, чанки.
- `cache/` — кэш ответов LLM и готовых карточек (в git не попадает, кроме `replay`-набора, который добавим отдельно).
