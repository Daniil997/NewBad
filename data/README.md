# Данные приложения

`app.sqlite3` — аккаунты, профили, настройки, новости, котировки, общий банковский корпус, персональные рекомендации, анализы и чаты.
`journal.sqlite3` — журнал вызовов моделей и кэш повторного воспроизведения.
`bank/corpus.sqlite3` — поставляемая база знаний из девяти материалов кейса, без пользовательских данных. Автоматически устанавливается в рабочую SQLite; входит в Git и Docker-образ.
`bank/extracted/` и `tessdata/` — прежние локальные результаты и средства OCR; сервис их не читает.
`news/imported/` — временный каталог совместимости для импорта старых публикаций; актуальные новости хранятся в SQLite.

Новая установка не создаёт аккаунты или внешние новости. Общая аналитика банка доступна сразу; персональные связи формируются по профилю и новости. Подробности: [банковский корпус](bank/README.md).

Рабочие базы, кэши, результаты OCR и секреты исключены из Git. Для резервной копии рабочей SQLite используйте SQLite backup API либо остановите API перед копированием файлов.
