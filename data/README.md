# Данные

- `raw/` — исходные CSV и PDF кейса. В git не попадают (см. `.gitignore`).
- Выгрузка компаний, платежей и связей физлиц лежит в `DATA` рядом с репозиторием: `df_Uid_data_hack.csv`, `df_Uid_payment_hack.csv`, `df_Fid_Uid_link_hack.csv`. PDF аналитики банка остаются в `Doc/Данные данные`. При запуске приложения CSV подхватываются сами. В интерфейсе для показа три компании из `config/case_clients.yaml`. Показатели профиля туда не записываются, они читаются из CSV. Полный список на 85 тысяч компаний в переключатель не выводится. Тесты читают `demo/`.
- `demo/` — синтетические демо-клиенты, попадают в репозиторий и используются тестами.
- `news/` — корпус новостей: JSON с источником, датой, URL, выдержкой и извлечёнными фактами.
- `bank/` — паспорта материалов банка: тезисы, допустимые цитаты с номером страницы, чанки.
- `cache/` — кэш ответов LLM и готовых карточек (в git не попадает, кроме `replay`-набора, который добавим отдельно).
