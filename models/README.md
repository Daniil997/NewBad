# Веса моделей

В git файл не кладём. Для этой машины нужен один официальный файл:

`models/gemma-4-26B_q4_0-it.gguf`

Это Gemma 4 26B A4B, QAT Q4_0, около 13.5 ГиБ:

https://huggingface.co/google/gemma-4-26B-A4B-it-qat-q4_0-gguf

Проектор картинок `gemma-4-26B-it-mmproj.gguf` не нужен: новости читаем как текст.

Скачивание из приложения и из браузера не запускается. На этой машине веса лежат в Ollama: `gemma4:26b-a4b-it-qat`, для приложения имя `gemma-4-26b-a4b`. Адрес `http://127.0.0.1:11434/v1`.

Авторежим перед запросом читает свободную видеопамять. Если её меньше примерно 16,5 ГБ, все слои на видеокарту не требуем: хвост остаётся в оперативной памяти. Качество от этого не меняется, ответ становится медленнее. Контекст запроса — 4096, чтобы служба не разворачивала свой запас в 65536.
