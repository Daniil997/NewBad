# Интерфейс

Стек зафиксирован: TypeScript, React, Vite. Приложение появляется на этапе 5 плана работ. Обязательные экраны: главная Альфа-Бизнеса с виджетом, лента, карточка, панель «Как получен вывод», чат уточнений, страница режима модели. Шаги агента стримим через SSE.

Страница новостей в тестовом и реальном режимах использует общие компоненты из `src/NewsWorkspace.tsx` и стили `src/news.css`: шапку, контекст компании, ленту с поиском и фильтрами, заголовок публикации, оценку связи и блоки разбора. Специфичные данные и действия подключаются в `Service.tsx` и `RealMode.tsx`. Изменения общего дизайна следует вносить в общие компоненты.

Фильтры последних дней в реальном режиме отсчитываются от текущей локальной даты, в тестовом — от последней даты набора. Это позволяет просматривать исторические тестовые материалы. Счётчик «Все новости» в реальном режиме исключает публикации курсов валют, вынесенные в отдельный виджет.

В обоих режимах доступна сортировка «По важности», «Сначала новые» и «Сначала старые». По умолчанию используется оценка важности; при одинаковой оценке первыми идут новые публикации. Новости без оценки располагаются после оценённых. Сортировка применяется к результатам поиска и фильтров, сохраняется при обновлении ленты и переключении вкладок, а сброс фильтров её не меняет.

В реальной карточке всегда есть раздел «Что говорят аналитики банка». Пока редакционного текста для компании нет, он явно отмечен как заглушка «Здесь будут рекомендации от Альфа-Бизнеса». В «Настройках разработчика → Рекомендации банка» сначала нужно найти и выбрать реальный профиль компании, затем новость. Доступны поиск по компании, аккаунту, отрасли и городу, контекст выбранного профиля, текст индивидуальной оценки и необязательный номер страницы. Предпросмотр показывает результат для выбранной компании. При смене профиля выбранная новость сохраняется, а текст загружается для новой компании. Очистка текста возвращает заглушку только этому профилю; отмена восстанавливает его сохранённый текст. При смене профиля, новости, раздела или выходе учитываются несохранённые изменения.

Оценки хранятся в SQLite в таблице `profile_bank_recommendations`, ключ — пара `(profile_id, news_id)`. Они не зависят от автоматически созданного разбора и сохраняются при обновлении профиля, повторном импорте и дополнении текста новости. Реальная лента читает оценки только профиля текущего пользователя. Схема базы 14 сохраняет прежние общие тексты, но не назначает их компаниям автоматически: редактор позволяет явно скопировать такой текст выбранному профилю. Профили: `GET /api/settings/news/recommendation-profiles`; новости и оценки: `GET /api/settings/news/recommendations?profile_id=...`; сохранение: `PUT /api/settings/news/{news_id}/recommendation` с JSON `{ "profile_id": "...", "text": "...", "page": null }` и CSRF-заголовком. Без профиля запись не допускается. Тестовый разбор продолжает показывать свои исходные материалы банка.

Тема и её подпись (`event_type`, `event_title`) определяются при импорте и сохраняются вместе с публикацией в SQLite или JSON. Миграция схемы 11 однократно заполняет темы уже собранных новостей. Ленты разных компаний читают общие сохранённые значения; обновление подборки не меняет подпись. Повторный импорт и дополнение текста не заменяют сохранённую тему. Для старых сторонних JSON без этих полей остаётся совместимый путь чтения. Явная тема заголовка имеет приоритет перед побочными упоминаниями в тексте; при недостатке свидетельств показывается нейтральное «Новости бизнеса».

В карточках список строится в пределах доступной ширины: длинные категории и названия источников переносятся, при нехватке места дата и метка связи переходят на следующую строку. Для регрессии следует проверять не только ширину страницы, но и `scrollWidth` самой карточки и её строк.

Проверка сборки: `npm run build`. При проверке интерфейса нужно пройти оба режима: поиск с пустым результатом и сбросом, категории и период, переключение новости, загрузку и повтор после ошибки. На ширине 320/390 px лента и разбор располагаются друг под другом; ссылка «К ленте новостей» возвращает к списку. При ширине от 861 px отображаются две колонки.
