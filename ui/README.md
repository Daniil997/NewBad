# Интерфейс NewBad

React + TypeScript + Vite. Установка: `npm ci`; запуск: `npm run dev`; проверка и сборка: `npm run build`. Vite направляет `/api` на API по адресу `127.0.0.1:8000`.

`App.tsx` открывает главную, настройки разработчика и рабочее пространство `RealMode.tsx`. Вход выполняется по аккаунту, профиль редактируется в `CompanyProfile.tsx`. Лента и карточки используют `NewsWorkspace.tsx`, `RealParts.tsx` и `news.css`. Диалоги открываются в `ChatWorkspace.tsx`.

`DataRefreshProvider` сохраняет состояние обновления между страницами. Кнопка в шапке запускает `/api/data/refresh`; опрос состояния продолжается до завершения. Событие `business-data-updated` перечитывает ленту, котировки и историю инструментов. Настройки разработчика изменяют параметры сбора, показывают диагностику и позволяют отдельно собрать новости или рыночные данные кнопкой «Собрать сейчас» / «Сохранить и собрать». Общий запуск обоих сборщиков также доступен в шапке главной и рабочего пространства.

Рекомендации банка сохраняются для пары `(profile_id, news_id)` и читаются только текущим профилем. Запись требует CSRF. Даты фильтров ленты отсчитываются от текущей локальной даты.
